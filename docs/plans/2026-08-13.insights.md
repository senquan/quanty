## 💡 经验总结

1. **FastAPI 路由模块化模式**：端点按功能拆分到独立文件（auth/user/roles/menu/quant/trading），根 api.py 只做 router 聚合。这种方式便于团队成员并行开发、代码审查更聚焦。

2. **偏好配置分层架构**: `preferences.ts` 使用 `defineOverridesPreferences()` + `overridesPreferences` 导出，结合运行时 `getAppPreferences()` / `setAppPreferences()`，实现 "默认值 + 用户覆盖" 两层模型。建议将此模式复用到应用全局配置中。

3. **前后端解耦部署**: `accessMode: 'frontend'` 表示前端独立完成权限判断（localStorage/JWT），后端 API 为无状态或共享 session。部署时无需后端参与认证，降低运维复杂度。

4. **因子库可视化组件设计模式**: 
   - `factor-card.vue` (展示) → `factor-editor-modal.vue` (交互编辑) → `factor-library.vue` (列表管理) 形成组件链
   - `backtest-studio.vue` + `correlation-heatmap.vue` + `efficacy-deep-dive.vue` 是高级分析子模块
   - **建议**: 后续可提取公共 hooks/useFactor.ts 用于因子数据状态管理

5. **文档先行策略**: Commit 中包含 `quant-closed-loop-roadmap.md` (215行) + `short-term-dev-plan.md` + `tech-debt-memo-2605.md`，说明开发过程中保持规划文档同步的习惯值得持续。
