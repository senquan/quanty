- 状态：实施完成（代码已落地并通过 lint + 烟测；仅数据灌入需用户手动跑脚本）

## 目标

1. 用 akshare 把 `factor.finance_reports` 从 2021 起**所有报告期**补全（现状只刷近 8 期 ≈ 2 年，深度历史是洞）。
2. 在因子层把文档确认**无历史数据源**的因子（`VAL_PB` / `VAL_PS_TTM` / `VAL_DIV_YIELD`）标记为 `unavailable`，并从覆盖率分母剔除，消除"覆盖率永远卡 32% 假象"。

## 现状证据（带文件行号）

- **回补入口只覆盖近 2 年**：`app/tasks/fundamental_refresh.py:99-124` `refresh_growth(periods)` 用 `recent_periods(8)`（近 8 期），不拉 2021-2026 全历史；`refresh_daily_fundamental` 仅刷 `_latest_trade_date()` 当天。
- **成长表可 bulk 回补且免费**：`app/ingestion/fundamental_source.py` `fetch_growth_akshare_bulk` 每期 1 次 `stock_yjbb_em(date=p)` 调用，分钟级；`prefer_growth_provider()`（同文件 255-272）因本账户 tushare `fina_indicator` 无权限 → 自动走 akshare。
- **upsert 幂等、按 (symbol,report_period) 合并**：`app/storage/fundamental_store.py:113-152` `upsert_finance_reports` 用 `COALESCE` 保证成长路径与财务指标路径互不覆盖，重跑安全。
- **PE 经 eps_ttm 推导，依赖 finance_reports**：`app/tasks/factor_build.py:58-73` `_merge_fundamental` 中 `fr["eps_ttm"] = fr["eps"].where(fr["_rp_month"]==12).ffill()`；`app/factors/fundamental.py:15-35` `VAL_PE_TTM` 用 `adj_close/eps_ttm` 推导。故 finance_reports 补完后 `VAL_PE_TTM`、成长、`FND_ROE/FND_DEBT_RATIO` 自动得解。
- **估值真实 PE/PB/PS/DV 无源（文档定论）**：docs/memo/2026-09-02.md §2.4 — tushare 低权限历史 `daily_basic` 全 0 行；pandadata 仅指数级 PE/PB/PS；akshare 历史估值单标的接口不现实。`PB`、股息率**永久无解**。
- **value 类因子注册**：`app/factors/fundamental.py` — `VAL_PB`(39)、`VAL_PS_TTM`(53)、`VAL_DIV_YIELD`(67)、`VAL_PE_PERCENTILE`(88，回退价分位故可得)。三者 `data_sources` 仅 `pb`/`ps_ttm`/`dividend_ttm,div_yield`，均无历史源。
- **覆盖率分母在调试脚本**：全仓搜 `覆盖率/coverage` 仅在 raw_bars 覆盖度与调试脚本 `data-cleaner/_verify_full.py`（逐因子 `s.notna().mean()`）；app 生产代码无因子级覆盖率分母。故"剔除分母"作用在 `Factor` 元数据 + `_verify_full.py`。

## 架构 / 方案

- 新增可断点回补函数，复用既有 akshare bulk 链路，不改动每日调度 `refresh_growth`（最小改动）。
- 断点状态落 `data/growth_history_state.json`（已完成期 + 指标阶段标记），中断重跑续跑。
- 因子层加 `unavailable` 标记，任何未来/生产覆盖率分母均应据此剔除（本次先在 `_verify_full.py` 落地）。

## 更正 2026-09-09

原"目标 2 / 改动清单"称 `VAL_PB`/`VAL_PS_TTM`/`VAL_DIV_YIELD` 三者均 unavailable——**此结论已推翻**。
实测 akshare 1.18.64：`stock_zh_valuation_baidu` 可按标的返回完整日频 **PB / 市盈率(TTM)** 历史；
`stock_fhps_em(date=YYYY1231)` 返回全 A **年度股息率**。即 PB/PE_TTM/股息率均可经 akshare 回补，
仅 **PS_TTM（市销率）百度不支持**仍无解。故最终只保留 `VAL_PS_TTM` 为 unavailable，
`VAL_PB`/`VAL_DIV_YIELD` 已撤销标记。估值历史回补的实施见
`docs/plans/2026-09-09.valuation-history-backfill.md`。

## 更正 2（2026-09-09，akshare 1.18.94）

**PS_TTM 也有源了，四个估值因子全部可回补。** 实测 `ak.stock_value_em(symbol="600519")`
（东财个股估值接口）一次返回该标的 `2018-01-02 ~ 2026-09-08` 共 2108 行日频历史，列含
`['数据日期','PE(TTM)','市净率','市销率', ...]`。即**单标的一次调用同时拿齐 PB / PE(TTM) / PS(TTM)**，
比 `stock_zh_valuation_baidu`（百度只给 PB/PE、市销率报 None）更优，应作为估值历史回补的主接口。

逐因子取数映射（均走 akshare，免费）：
- `VAL_PB`      ← `stock_value_em` 的 `市净率`
- `VAL_PE_TTM`  ← `stock_value_em` 的 `PE(TTM)`（注：因子层另有按 `adj_close/eps_ttm` 推导路径，二选一/合并）
- `VAL_PS_TTM`  ← `stock_value_em` 的 `市销率`  ← **原 unavailable，现可解**
- `VAL_DIV_YIELD` ← `stock_fhps_em(date=YYYY1231)` 的 `现金分红-股息率`（年度，小数→%）

故 `VAL_PS_TTM` 的 `unavailable` 标记也应撤销；`_verify_full.py` 覆盖率分母不再剔除任何估值因子。
估值回补实现统一收敛到 `stock_value_em`（单标的全历史）替代原"百度 PB/PE + 东财股息率"双接口方案，
详见 `docs/plans/2026-09-09.valuation-history-backfill.md`（需同步更新其取数实现）。
