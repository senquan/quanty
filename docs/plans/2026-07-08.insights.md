### 1. FastAPI Endpoint Pattern — Modular Router Assembly
**File:** `backend/app/api_v1/endpoints/menu.py` (new), `api.py` (modified)

**Pattern Discovered:**
```
api.py                    endpoints/
│                         └── menu.py  ← new endpoint module
│    ├── auth.router       ├── backtest-studio.vue → API call
│    ├── user.router       ├── factor-card.vue     → API call  
│    └── menu.router (new) └── factor-library.vue  → API call
```

**Key Conventions:**
- Endpoint files: each domain gets its own file under `endpoints/`
- Router registry: single `api.py` as assembly point with `include_router()` calls
- Return format: `Response.success(data=...)` wrapped responses (not raw dicts)
- Naming: singular router name (`menu.router`) vs plural mount prefix (`/menus/all`)
