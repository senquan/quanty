## 💡 经验总结

1. **异步/同步混合架构的陷阱**：代码在 `async def` 函数中使用同步 `Session`，需注意 FastAPI 的依赖注入是否配置了 `run_in_threadpool`，否则同步操作会阻塞 AsyncIO 事件循环。

2. **响应格式一致性**：REST API 端点的返回值应保持一致的封装格式（如统一 `Response.success()`），这有助于前端统一处理且减少 API 文档混乱。

3. **字符串序列化安全**：从外部（如 JSON、数据库、API 响应）序列化字符串再写回 Python 代码时，双引号的转义处理是关键——直接使用单引号包裹 Python 字符串可以避免转义问题。

4. **代码精简策略**：移除不常用或冗余的端点（`update_strategy`/`delete_strategy`），可以减少维护负担，但需确保前端确实不再需要这些功能。
