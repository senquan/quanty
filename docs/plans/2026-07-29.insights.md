1. **网络容错是 CI/CD 的关键**：本次 fetch 全部超时，导致 insights 提取只能基于历史数据。建议在方案中加入 `git clone --mirror` 预缓存机制。

2. **Factor Library 是值得复用的组件库**：correlation-heatmap.vue、factor-card.vue 等组件可提取到 shared 目录，避免未来重复开发。

3. **从 mock → production 的迁移策略**：先双写验证，再灰度切换，最后移除 mock——这个模式通用性强。
