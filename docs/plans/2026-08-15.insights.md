### ♻️ 重构优化

#### UI 文本字号统一调整 (commit `360c119`)
- **变更**: 回测工作室中所有 text-[10px] → text-[11px]
- **原因**: font-size: 10px 在 Retina/高分辨率屏上过细不易读
- **经验**: Element Plus + Tailwind 混合项目中，Tailwind class 优先级低于 Element Plus SCSS 变量时需注意！text-[10px] 被 el-button 样式覆盖导致不生效，text-[11px] 因字体更粗故显示正常——**最小可读字号建议 ≥11px**

- **经验**:

## 💡 经验总结

### 1. AI 代码生成后需手动 cleanup（qoder/claude/codex 通用）
- Qoder Quests Qwen3.7-Max 生成的 `13d7208` commit 包含完整 factor UI，但后续有 4 个 fix commits (b288e5b → bf24b78 → 0b4aafe → 360c119)
- **教训**：AI 批量生成代码 → review → 移除 mock → API对接 → style tweaks，典型流程需 4-5 个迭代 commit

### 2. Tailwind CSS 与 Element Plus 样式覆盖陷阱
- Tailwind `text-[10px]` 在 el-button/el-tag 内可能被 SCSS override 为默认字号
- **最佳实践**：对 Element Plus 内部元素使用 text-[11px] 以上，或用 `!important` / scoped CSS

### 3. FastAPI Router inclusion 模式
- backend 采用 `include_router` pattern: `_api_v1_router.include_router(menu.router, prefix="/api/v1/menu")`
- Response wrapper 统一包装为 `{code, message, data}` → 前端 type guard 简化

### 4. Monorepo pnpm 工作区结构

│   ├── vite.config.ts
│   └── src/         # Vue components + views
