## 💡 经验总结

1. **Commit Hash Reuse via Rebase**: `955f89c` 和 `360c119` 是同一内容在不同分支的历史 replay，hash 不同但内容相同。rebase 检测并 skipped pre-applied commit — 利用 git 的 patch-id 去重机制避免重复提交。

2. **Vue Component Granularity**: factor components 按功能模块高度拆分（card, editor, filter, backtest），每个组件职责单一，适合团队协作和 UI 复用。

3. **FastAPI Router Convention**: backend API 遵循 `app/api/api_v1/endpoints/<domain>.py` 的 pattern — 每个 domain (auth, user, quant, menu) 独立文件，便于扩展和维护。

4. **Preferences-Driven Configuration**: frontend config (`preferences.ts`) 管理 app-wide settings (accessMode, logo, theme)，降低硬编码依赖，支持运行时切换。
