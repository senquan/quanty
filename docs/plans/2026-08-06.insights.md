- **关键点**: 
  - IC阈值 >0.03, IR >0.5 作为因子筛选标准

- **模式**: 批量替换但保持命名空间一致性

## 💡 经验总结

### 关键经验 (Top Insights)

1. **Token-Based Auth 是渐进式迁移**
   - 认证从 session → token 的迁移涉及：前端 interceptor + axios proxy config + .env + 后端 auth.py endpoints
   - `preferences.ts` 控制 accessMode（混合模式 vs 纯前端模式），影响登录跳转行为

2. **FastAPI Router 注册最佳实践**
   ```python
   # 推荐模式：每个 endpoint 模块独立 file → router import → api.py include
   # 新增模块 = 1个新文件 + api.py 加2行 (import + include_router)
   ```
   - 好处：低耦合，每个业务模块自包含

3. **量化因子筛选标准**
   - IC均值 >0.03（>0.05 为优质因子）
   - IR >0.5（稳定性指标）
   - 月换手 <30%（避免过度交易）
   - 因子间两两相关 <0.5（去除共线性）

4. **UI 可读性优化模式**
   - Tailwind 组件中文体微调（1px提升=显著体验改善，尤其是在高分辨率屏幕）
   - 需要系统化：定义 text-sm-base + text-xs-base scale，避免散乱使用 `[9px]`-`[14px]`

5. **跨平台文件名规范**
   - WSL2环境下中文路径兼容性差（WSL <-> Windows文件交换时编码问题）
   - 文档统一英文命名或 kebab-case（`quant-closed-loop-roadmap.md`）
