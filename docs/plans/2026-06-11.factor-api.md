# 因子库后端 API 接口需求

> 优先级: P0 (必须) / P1 (重要) / P2 (可选)
> 创建日期: 2026-06-11
> 前端对接文件: `frontend/apps/web-ele/src/views/data/factor/mock/factor-service.ts`

## P0: 因子 CRUD（核心功能）

### 1. 获取因子列表
- **Method**: `GET`
- **Path**: `/api/v1/factor/`
- **Query Params**:
  - `category?: string` — 因子类别 (momentum/volatility/value/growth/sentiment/custom)
  - `author?: string` — 作者来源 (system/user)
  - `frequency?: string` — 更新频率 (Daily/Weekly/Monthly/Quarterly)
  - `search?: string` — 关键词搜索 (匹配 name/code/formula)
- **Response**: `Factor[]`
- **说明**: 返回所有因子，含完整序列数据 (dates, icSeries, longReturns, shortReturns, benchmarkReturns)

### 2. 获取单个因子详情
- **Method**: `GET`
- **Path**: `/api/v1/factor/{id}`
- **Response**: `Factor`

### 3. 创建因子
- **Method**: `POST`
- **Path**: `/api/v1/factor/`
- **Request Body**:
```json
{
  "name": "因子名称",
  "code": "FACTOR_CODE",
  "category": "momentum",
  "frequency": "Daily",
  "formula": "(close - delay(close, 20)) / std(close, 20)",
  "description": "因子说明",
  "dataSources": ["日K收盘价"]
}
```
- **Response**: `Factor` (含后端生成的 id, createdAt, 以及计算后的效能指标)
- **说明**: 后端需根据 formula 执行因子计算，生成 icMean/icStd/ir/sharpeRatio 等指标及序列数据

### 4. 更新因子
- **Method**: `PUT`
- **Path**: `/api/v1/factor/{id}`
- **Request Body**: `Partial<Factor>` (同创建接口字段)
- **Response**: `Factor`

### 5. 删除因子
- **Method**: `DELETE`
- **Path**: `/api/v1/factor/{id}`
- **Response**: `204 No Content`
- **说明**: 仅允许删除 author=user 的因子，系统因子不可删除

## P1: 分析与回测（重要功能）

### 6. 因子相关性矩阵
- **Method**: `POST`
- **Path**: `/api/v1/factor/correlation`
- **Request Body**:
```json
{
  "factor_ids": ["id1", "id2", "id3"]
}
```
- **Response**:
```json
{
  "matrix": {
    "CODE_A": { "CODE_A": 1.0, "CODE_B": 0.35 },
    "CODE_B": { "CODE_A": 0.35, "CODE_B": 1.0 }
  }
}
```
- **说明**: 基于因子在全市场的暴露值计算 Pearson 相关系数

### 7. 多因子组合回测
- **Method**: `POST`
- **Path**: `/api/v1/factor/backtest`
- **Request Body**:
```json
{
  "selectedFactorIds": ["id1", "id2"],
  "weightMethod": "ic_weighted",
  "benchmark": "CSI300",
  "startDate": "2025-06",
  "endDate": "2026-05",
  "rebalancePeriod": "Monthly",
  "transactionFee": 0.0015
}
```
- **Response**:
```json
{
  "dates": ["2025-06", "..."],
  "portfolioReturns": [100.0, 102.5],
  "benchmarkReturns": [100.0, 101.2],
  "excessReturns": [0.0, 1.3],
  "metrics": {
    "totalReturn": 12.5,
    "annualizedReturn": 12.5,
    "benchmarkReturn": 10.2,
    "sharpeRatio": 1.85,
    "maxDrawdown": 8.2,
    "informationRatio": 1.2,
    "beta": 0.92,
    "alpha": 3.5,
    "turnoverRate": 15.0
  },
  "factorWeights": { "MOM_20": 0.35, "RSI_14": 0.65 }
}
```

## P2: AI 辅助（可选功能）

### 8. AI 因子生成
- **Method**: `POST`
- **Path**: `/api/v1/factor/ai-generate`
- **Request Body**:
```json
{
  "category": "momentum"
}
```
- **Response**: `Factor` (含 AI 建议的 name/code/formula 及计算后的完整数据)
- **说明**: 调用 LLM 或预置模板生成因子建议，前端自动添加到因子库

## 数据类型参考

```typescript
type FactorCategory = 'momentum' | 'volatility' | 'value' | 'growth' | 'sentiment' | 'custom';
type UpdateFrequency = 'Daily' | 'Weekly' | 'Monthly' | 'Quarterly';

interface Factor {
  id: string;
  name: string;
  code: string;              // 唯一标识，如 MOM_20
  category: FactorCategory;
  description: string;
  formula: string;           // 因子计算公式表达式
  dataSources: string[];     // 依赖的数据源列表
  frequency: UpdateFrequency;
  status: 'active' | 'draft';
  author: 'system' | 'user';
  createdAt: string;         // ISO date

  // 效能评测指标
  icMean: number;            // IC均值
  icStd: number;             // IC标准差
  ir: number;                // 信息比率 (IC/IC_std)
  winRate: number;           // 胜率
  maxDrawdown: number;       // 最大回撤 (小数)
  sharpeRatio: number;       // 夏普比率

  // 时间序列数据
  dates: string[];           // 日期列表 (月度)
  icSeries: number[];        // 月度IC序列
  longReturns: number[];     // 多头累计净值 (起点100)
  shortReturns: number[];    // 空头累计净值 (起点100)
  benchmarkReturns: number[];// 基准累计净值 (起点100)

  // 用于相关性计算的全市场暴露值
  mockUniverseValues: number[];
}
```

## 对接说明

前端当前使用 `factor-service.ts` 中的 mock 实现。接入真实 API 时，只需将 `factorService` 中的方法替换为 HTTP 请求调用即可，无需修改任何 Vue 组件代码。建议对接路径：

1. 创建 `frontend/apps/web-ele/src/api/factor.ts`，参考 `api/quant.ts` 模式使用 `requestClient`
2. 修改 `factor-service.ts` 导入真实 API 方法替代 mock 函数
