## 🚀 API Router 模块化注册

### 经验
FastAPI端点通过独立module的router暴露，主api.py集中`include_router()`。新增业务域无需修改注册文件，git merge-conflict风险大幅降低。

**代码结构范式：**
```
frontend/apps/web-ele/src/api/core/
├── index.ts           # 统一 baseURL + interceptor
├── menus.ts           # menu CRUD endpoints
```

**好处：**
- mock切换时只需改adapter layer，各组件代码不变

- endpoint职责单一，新增endpoint不产生merge-conflict

## 🐛 SQLAlchemy AsyncSession 强制规范

### 问题场景
`quant.py` 使用同步`Session`但endpoint中有await调用→ `RuntimeError: This event loop is already running`。

### 修复方案
```python
# ✅ 正确：所有DB操作使用AsyncSession + await
from sqlalchemy.ext.asyncio import AsyncSession
async def get_users(db: AsyncSession = Depends(get_db)):
    result = await db.execute(select(User))
    items = result.scalars().all()
```

### Python async/sync对照表
| 同步Session | 异步AsyncSession | 说明 |
|-------------|------------------|------|
| `engine = create_engine()` | `create_async_engine()` | engine创建方式不同 |
| `session = Session(engine)` | `AsyncSession(async_engine)` | session类型声明 |
| `result = session.execute(stmt)` | `await db.execute(stmt)` | execute需要await |
| `session.commit()` | `await db.commit()` | commit/refresh都需要await |

### SQLAlchemy 2.0 delete语法
新项目使用 `delete(Model).where(...)` 而非旧版 `func.delete(Model)`。需验证MySQL方言兼容性。

## 📦 Pydantic + Pagination 最佳实践

### 分页双重查询模式
```python
# count query和data query的WHERE条件必须一致
total_query = select(func.count(User.id)).where(or_(User.username.ilike(pattern), ...))
data_query = select(User).where(...).offset(skip).limit(limit)
total = (await db.execute(total_query)).scalar() or 0
```

### serialize helper模式
将ORM model → Pydantic schema转换封装为独立async函数（如`serialize_user()`），避免各endpoint重复编写`.copy()`/`pop('_sa_instance_state')`逻辑。可复用到所有Entity。
