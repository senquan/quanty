# 投资组合(Portfolio)牵头改造 — 实施方案

- **状态**：实施完成（后端导入通过 / 前端 vue-tsc 改动文件零错误；存量迁移幂等自愈，待后端首次启动触发）
- **日期**：2026-09-05
- **目标**：以「投资组合」(`Portfolio`) 取代现有「以策略牵头的模拟盘」，成为交易域的一等公民。组合可指定投资策略、拥有独立资金池与持仓；前端在「量化概览」下方新增「投资组合」菜单。

---

## 1. 目标与范围

1. 前端 `量化` 菜单在「量化概览」下方新增「投资组合」入口(`/quant/portfolio`)。
2. 新增 `portfolios` 表，作为交易域**牵头实体**：绑定一个策略、独立资金池、独立持仓。
3. 现有「以 `(mode, strategy_id)` 自动建账户」的模拟盘模型**整体替换为组合牵头**：持仓 / 订单 / 成交 / 调仓记录 / 每日估值全部改挂 `portfolio_id`。
4. 提供组合的 CRUD 接口与页面：创建(命名 + 选策略 + 初始资金 + 模式 + 是否自动调仓)、查看资金池/持仓/调仓历史/收益曲线、单组合手动触发调仓。
5. 调仓调度从「遍历启用策略」改为「遍历开启自动调仓的组合」。

### 假设(待确认，先按此推进)
- **A1**：一个组合绑定**一个**策略(1:1)。多策略组合留作后续扩展。
- **A2**：组合同时覆盖 `paper` / `live` 两种 `mode`(统一由组合牵头；"模拟盘"= `mode=paper` 的组合)。
- **A3**：存量 `trading_accounts`(per `mode+strategy_id`)**迁移**为组合(同源 id 复用)，持仓/订单/成交的 `account_id` 改名 `portfolio_id` 后值仍有效；提供一次性迁移脚本。
- **A4**：`trading_accounts` 表**删除**，其职责完全由 `portfolios` 承接(即"替换")。
- **A5**：组合每日估值 `PortfolioDailyValue`、调仓记录 `TradingRebalanceRecord` 改以 `portfolio_id` 为主键维度，保留 `strategy_id` 冗余便于归因。
- **A6**：`交易管理 (/quant/trading)` 页面保留，后续改为"选择组合"后查看该组合订单/成交(本次可仅做组合牵头改造，该页面重指向留作下一步)。

## 3. 目标架构

```
                 ┌─────────────────────────────────────┐
   前端 /quant/portfolio  ──►  POST/GET/PUT/DELETE /portfolios
                 │               GET /portfolios/{id}/{overview,positions,rebalances,values}
                 │               POST /portfolios/{id}/rebalance
                 ▼
   backend 交易中心
     Portfolio (牵头实体, 独立资金池)
        │ 1:1
        ▼
     Strategy(strategies.code = 配置 JSON)
        │
        └─ 调仓: proxy.scores(config) → 目标持仓 (dc 纯计算)

   TradingCoordinator(db, portfolio_id)   ← 由 (mode,strategy_id) 改为 portfolio_id
     ├─ 读 portfolio: mode / strategy_id / cash_balance / frozen_cash
     ├─ 下单 / 同步持仓 / 回灌撮合内存
     └─ 落库: positions / orders / trades 全部挂 portfolio_id

   调度: scan_and_rebalance → 遍历 auto_rebalance & is_active 的组合(替代"启用策略")
```

### 3.1 新表 `portfolios`(承接并取代 `trading_accounts`)
```python
class Portfolio(Base):
    __tablename__ = "portfolios"
    __table_args__ = (
        UniqueConstraint("owner_user_id", "name", "mode", name="uq_portfolio_owner_name_mode"),
    )
    id = Column(Integer, primary_key=True, autoincrement=True)
    name = Column(String(128), nullable=False)                 # 组合名(用户命名)
    strategy_id = Column(Integer, ForeignKey("strategies.id"), nullable=False, index=True)
    mode = Column(String(16), nullable=False, default=MODE_PAPER, index=True)
    broker = Column(String(32), nullable=False, default="simulated")
    owner_user_id = Column(Integer, ForeignKey("users.id"), nullable=True, index=True)
    initial_capital = Column(Float, nullable=False, default=0.0)
    cash_balance = Column(Float, nullable=False, default=0.0)   # 独立资金池
    frozen_cash = Column(Float, nullable=False, default=0.0)
    auto_rebalance = Column(Boolean, nullable=False, default=True)
    is_active = Column(Boolean, nullable=False, default=True)
    account_id = Column(String(64), nullable=False)             # 券商/模拟器返回账户号(兼容现有字段)
    description = Column(Text, nullable=True)
    created_at = Column(DateTime(timezone=True), server_default=func.now())
    updated_at = Column(DateTime(timezone=True), server_default=func.now(), onupdate=func.now())
```
