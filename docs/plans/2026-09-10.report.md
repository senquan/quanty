**处置**：已执行
```bash
git remote set-url origin https://x-access-token:<token>@github.com/senquan/quanty.git
```

PAT 授权校验组合下旧 URL 直接 404）。

### 架构变化（来自 docs/memo/architecture.md）

系统从单体后端演进为 **三层微服务**：

```
前端 Vue3 + Vben (web-ele :5777)
  → backend 主后端 :8000  (FastAPI + async SQLAlchemy, quant_db :5432 + Redis)
    → data-cleaner 因子引擎 :8100  (FastAPI + APScheduler, factor_db :5433, Parquet)
```

**关键决策（§0 回测归口）**：回测一律放在 dc 端，backend 不持有回测计算、只做网关转发。
原因是 A 股行情数据在 dc 的 `factor.raw_bars`（6,118,948 行 / 5,555 只），backend 与 dc 两库隔离、
无法直连。backend 现有回测只挂 yfinance/ccxt，无 A 股——"回测引擎长在了没有数据的那一侧"。

**交互原则**：backend 与 dc 仅通过 HTTP（httpx + `X-API-Key`）交互。
