## 💡 经验总结

### 1. LLM 输出引号转义问题
FastAPI 项目中，当使用三引号字符串 (`\"\"\"`) 时，内部的普通引号需要正确转义。
**最佳实践**：检查生成的代码中 router 装饰器参数、字典键、异常 detail 字符串是否被正确转义。

### 2. 定期清理旧文档
项目长期运行产生的 report/insights/task 文件会不断堆积。
**建议**：设置周期性清理策略，保留最近 2-4 周的有效文档，其余归档或删除。

### 3. run_daily.sh 可废弃
该文件 289 行，包含完整的重试网络和任务管理逻辑。
**建议**：如果项目已迁移到 Hermes cronjob 机制，旧的 shell 脚本可统一清理，减少维护负担。

### 4. 分支领先与 rebase 方向
feature/hermes-corder 领先 origin/master 1 commit，但 trunk 有变更差异被本地分支覆盖。
**注意**：如果主干有重要合并（PR merge），需要定期 rebase origin/master 到 feature 分支。
