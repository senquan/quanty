### 📡 网络诊断经验（回顾）
- Proxy连接失败特征: `Failed to connect to 127.0.0.1 port 4780 after 0 ms: Connection refused`
- `after 0 ms` 表明 proxy 进程存活但拒绝新连接（非超时）
- 排查顺序：直连测试 → proxy端口监听 → SSL证书检查

## 💡 经验总结

### Git 操作最佳实践
1. fetch + rebase 应先于一切操作执行，确保基于最新代码工作
2. Feature分支与master保持同步可减少后续合并冲突
3. `merge.conflictstyle=diff3` 保留三方差异上下文，简化冲突解决

### Cron Job 作业经验
1. 网络重试策略：3次 × 30秒间隔对 cron job 是合理配置
2. 连续2天 fetch 失败时应触发 proxy 健康检查
3. 无变更时跳过 push 避免产生空 commit
