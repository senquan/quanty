# 增量保存全 A 股日线历史（raw_bars 历史库）

状态：✅ 已实施完成 — 2026-08-27

## 目标
将全 A 股日线历史行情（前复权）增量保存，支持每日更新，供因子重算/回测直接使用，
摆脱"每次按需 per-symbol 重拉"的无状态模式。

## 架构
```
Alphafeed REST (/v1/klines)           ← 行情源（已配置 ALPHAFEED_KEY）
        │ fetch(symbol,start,end)
        ▼
app.tasks.backfill.backfill_symbol / backfill_universe   ← 增量调度
        │ 仅拉 [latest+1day, today]（首次全量 2010-01-01 起）
        ▼
app.storage.raw_store.RawBarRepository.upsert            ← 双写
   ├─ PostgreSQL factor.raw_bars  (主存储, backend 直读)  ← migrations/002
   └─ parquet data/raw/{symbol}.parquet (本地降级/加速)
```

## API
- `GET /api/v1/raw/universe` — 全 A 股代码池（需 TUSHARE_TOKEN 或 akshare）
- `GET /api/v1/raw/{symbol}?start=&end=` — 读取历史（优先 PG）
- `POST /api/v1/raw/backfill` — 手动触发：`{source, symbols?, full?}`（后台任务）
- `GET /api/v1/raw/status` — 最近回填摘要（Redis 缓存，Redis 未起时 404）

## 验证结果
- `apply_migrations` 正确建表 + 函数（pg_proc 中 `upsert_raw_bars` 存在）
- 增量回填 600519.SH / 000001.SZ / 600036.SH / 000300.SH → PG `factor.raw_bars` 写入，
  `load('600519.SH', start='2025-01-01')` 返回 100 行，max ts = 2026-08-27
- `/raw/backfill` 后台 accepted；`/raw/600519.SH` 经 8100 返回 100 行（PG 直读）
- 二次 backfill 同标的 → skip（已是最新），符合增量语义

## 待办/注意
1. **全量代码池需 TUSHARE_TOKEN**：`get_a_share_universe` 优先 tushare `stock_basic`
   （轻量、权威），本环境未配 token，故 `/raw/universe` 返回 503。配 token 后即全量可用；
   或 `backfill_universe(symbols=[...])` 显式传代码列表绕过。
2. akshare 作为降级源在本 Windows venv 因 `curl_cffi` 依赖装不上（已 try/except 不阻断），
   建议全量统一用 tushare。
3. 每日 18:30 增量更新依赖 `ENABLE_SCHEDULER=true` + `RAW_BACKFILL_SOURCE=alphafeed`。
4. `/raw/status` 依赖 Redis；Redis 未运行时进度不持久化（不影响数据写入）。
