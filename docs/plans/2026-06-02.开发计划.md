## 三、修复方案

### P0-1：修复 quant.py AsyncSession 混用

**文件**：`backend/app/api/api_v1/endpoints/quant.py`

```python
# 修复前
from sqlalchemy.orm import Session
db: Session = Depends(get_db)

# 修复后
from sqlalchemy.ext.asyncio import AsyncSession
db: AsyncSession = Depends(get_db)
```

**说明**：全部 8 处 `Session` → `AsyncSession`，所有 `db.query()` → `db.execute(select(...))`，所有同步 commit/refresh → `await db.commit()` / `await db.refresh()`。

---

### P0-2：补全策略 PUT / DELETE 端点

```python
@router.put("/strategies/{strategy_id}", response_model=StrategyResponse)
async def update_strategy(
    strategy_id: int,
    strategy_data: StrategyUpdate,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    """更新策略"""
    result = await db.execute(
        select(Strategy).filter(
            Strategy.id == strategy_id,
            Strategy.user_id == current_user.id
        )
    )
    strategy = result.scalars().first()
    if not strategy:
        raise HTTPException(status_code=404, detail="策略不存在")

    # 代码变更时重新验证
    if strategy_data.code is not None:
        validator = StrategyValidator()
        validation = validator.validate_strategy(strategy_data.code)
        if not validation['valid']:
            raise HTTPException(status_code=400, detail=f"代码验证失败: {', '.join(validation['errors'])}")

    for field, value in strategy_data.model_dump(exclude_unset=True).items():
        setattr(strategy, field, value)

    await db.commit()
    await db.refresh(strategy)
    return strategy


@router.delete("/strategies/{strategy_id}")
async def delete_strategy(
    strategy_id: int,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    """删除策略（级联删除回测历史）"""
    result = await db.execute(
        select(Strategy).filter(
            Strategy.id == strategy_id,
            Strategy.user_id == current_user.id
        )
    )
    strategy = result.scalars().first()
    if not strategy:
        raise HTTPException(status_code=404, detail="策略不存在")

    # 级联删除回测历史
    await db.execute(
        delete(BacktestResultModel).where(BacktestResultModel.strategy_id == strategy_id)
    )
    await db.delete(strategy)
    await db.commit()
    return {"message": "策略已删除"}
```

## 七、量化专项建议

作为量化策略专家，针对系统本身提出以下补充建议：

### 1. 回测引擎增强
当前引擎使用 `exec()` 执行策略代码，存在以下局限：
- **未来改进方向**：引入 **vectorbt** 或 **backtesting.py** 作为回测内核，支持向量化回测，效率提升 10-100 倍
- **滑点模拟**：建议增加滑点参数（`slippage`），真实反映交易成本
- **手续费模型**：当前无手续费，需支持按比例/固定手续费

### 2. 因子研究框架
系统目前停留在"策略执行"阶段，建议增加：
- **因子库**：PE、ROE、MACD 等因子的标准化接口
- **IC 分析**：因子与收益的相关性验证
- **分组回测**：十分位组合表现对比

### 3. 数据质量
- **数据源验证**：Yahoo Finance 数据存在前复权/后复权不一致问题，需显式指定
- **数据缓存**：引入 Redis 缓存已获取的历史数据，减少重复请求
- **备用数据源**：建议接入 AKShare 作为国内股票数据备选

### 4. 风险控制模块
- **仓位管理**：Kelly 公式、固定比例、Dynamic Position Sizing
- **止损机制**：时间止损、价格止损、跟踪止损
- **持仓上限**：单标的持仓不超过总资产 X%
