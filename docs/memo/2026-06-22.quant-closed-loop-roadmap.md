## 阶段一：因子数据搜集（Milestone 1-3）

### M1：数据基础设施搭建（1-2 周）

| 任务 | 产出 | 验收标准 |
|------|------|----------|
| 确定数据源（Tushare/AKShare/Wind） | 数据源配置清单 | 能稳定获取日线数据 |
| 搭建本地数据库（SQLite/PostgreSQL） | 数据存储方案 | 日线/分钟线数据可读写 |
| 日线行情数据入库 | 覆盖沪深300+中证500成分股 | ≥3年历史数据，字段完整 |
| 复权处理逻辑 | 前复权/后复权函数 | 复权数据与行情软件一致 |

### M2：基本面因子库构建（2-3 周）

| 因子类别 | 具体因子 | 数据频率 |
|----------|----------|----------|
| 估值因子 | PE、PB、PS、股息率、EV/EBITDA | 季度/日频 |
| 盈利因子 | ROE、ROA、毛利率净利率、营收增速 | 季度 |
| 成长因子 | 营收YoY、利润YoY、经营现金流增速 | 季度 |
| 杠杆因子 | 资产负债率、流动比率、有息负债率 | 季度 |
| 质量因子 | 应收账款占比、商誉/净资产、审计意见 | 季度 |

**产出**：因子数据字典 + 标准化因子计算函数库（`factor_lib.py`）

### M3：技术面+另类因子扩展（2 周）

| 因子类别 | 具体因子 |
|----------|----------|
| 动量因子 | 1M/3M/6M/12M动量、动量反转 |
| 波动因子 | 历史波动率、下行波动率、振幅 |
| 成交量因子 | 量比、换手率、资金流向、OBV |
| 技术指标 | RSI、MACD、布林带宽度、ATR |
| 另类数据 | 北向资金净流入、融资融券余额变化、龙虎榜 |

**产出**：总计 ≥30 个候选因子的计算与存储

## 阶段二：因子驱动选股（Milestone 4-6）

### M4：单因子检验与筛选（2-3 周）

```
检验流程：
原始因子 → 去极值 → 标准化 → 分组回测 → IC/IR统计 → 因子排序
```

| 检验指标 | 说明 | 优选标准 |
|----------|------|----------|
| IC均值 | 因子与未来收益的相关性 | \|IC\| > 0.03 |
| IR比率 | IC的稳定性（IC均值/IC标准差） | \|IR\| > 0.5 |
| 分组收益单调性 | 多头组vs空头组收益差 | 单调递增/递减 |
| 换手率 | 因子值的稳定性 | 月换手 < 30% |
| 因子相关性 | 与已选因子的共线性 | 两两相关 < 0.5 |

**产出**：因子检验报告 + 优选因子清单（10-15个有效因子）

### M5：多因子合成模型（2-3 周）

```
选股模型流程：
优选因子 → 权重配置 → 合成得分 → 股票排名 → 组合构建
```

**权重配置方法**（由简到繁）：
1. **等权合成**（基线方案）：所有因子等权相加
2. **IC加权**：按各因子IC_IR赋权 → `w_i = IC_i / IR_i`
3. **最大化IR**：优化求解最优权重组合
4. **机器学习**：XGBoost/LightGBM 预测模型

**组合构建规则**：
- 排名前 N 只股票入选（N=20-50）
- 行业中性化：单行业暴露 ≤20%
- 个股权重：等权 / 市值中性化 / 风险平价
- 调仓频率：月度调仓（初期），后续可周度

**产出**：选股模型代码 + 月度调仓信号生成器

### M6：策略回测验证（2 周）

使用现有回测框架（`quant-backtest` skill）验证：

| 回测维度 | 关键指标 |
|----------|----------|
| 收益表现 | 年化收益、超额收益（vs 沪深300） |
| 风险指标 | 最大回撤、年化波动率、夏普比率 |
| 交易统计 | 胜率、盈亏比、换手率、交易成本占比 |
| 稳定性 | 滚动夏普、月度收益分布、分年度表现 |

**回测约束**：
- 交易成本：双边万三（0.06%）
- 滑点：0.1%（保守估计）
- 涨跌停限制：不能买入涨停/卖出跌停
- 停牌处理：剔除停牌股

**产出**：完整回测报告，夏普 > 1.5、最大回撤 < 15% 为达标线

## 阶段三：执行交易（Milestone 7-9）

### M7：交易接口对接（1-2 周）

| 任务 | 说明 |
|------|------|
| 选择券商API | QMT（迅投）/ Ptrade / 掘金量化 |
| 开通量化交易权限 | 联系券商申请 |
| API鉴权与连接 | 模拟盘环境搭建 |
| 基础交易函数封装 | 买入/卖出/撤单/查询持仓 |

**产出**：`trading_engine.py` — 统一交易接口层

### M8：模拟盘跑通（2-3 周）

```
模拟盘流程：
选股模型生成信号 → 信号校验（涨跌停/停牌/持仓） 
  → 生成交易指令 → 模拟执行 → 记录成交 → 日终对账
```

| 验证项 | 标准 |
|--------|------|
| 信号到指令转换正确率 | 100% |
| 模拟成交与理论偏差 | < 0.5% |
| 日终持仓与预期一致 | 偏差 0 股 |
| 跑通完整调仓周期 | ≥1个月无中断 |

### M9：小资金实盘（4-6 周）

| 项目 | 建议 |
|------|------|
| 初始资金 | 总资金的 10-20%（试探性） |
| 仓位上限 | 单票 ≤5%，总仓位 60-80% |
| 止损规则 | 个股 -8% 止损，组合 -12% 减仓 |
| 监控频率 | 每日收盘后自动对账 |
| 异常处理 | API断连/委托失败/撤单重试 |

**产出**：实盘交易日志 + 每周绩效跟踪表

## 阶段四：风控反馈与迭代（Milestone 10-11）

### M10：风控体系建立（2 周）

| 风控层级 | 规则 | 触发动作 |
|----------|------|----------|
| 个股级 | 单票最大亏损 -8% | 止损卖出 |
| 行业级 | 单行业暴露 >25% | 削减超配行业 |
| 组合级 | 组合最大回撤 >12% | 整体减仓至50% |
| 市场级 | 大盘跌破20日均线 | 降低总仓位至40% |
| 流动性 | 连续3日成交额 < 5000万 | 剔出持仓 |

### M11：策略迭代闭环（持续）

```
反馈循环：
实盘结果 → 因子有效性衰减检测 → 因子替换/新增 → 重新回测 
  → 模拟验证 → 实盘更新
```

| 迭代维度 | 频率 | 方法 |
|----------|------|------|
| 因子有效性监控 | 月度 | 滚动IC衰减检测 |
| 模型参数调优 | 季度 | 滚动窗口参数重拟合 |
| 因子池更新 | 半年度 | 新增/淘汰因子 |
| 整体策略复盘 | 年度 | 全面归因分析 |

## ⚠️ 关键风险提醒

1. **过拟合风险**：回测表现好不代表实盘好，始终保留样本外测试
2. **交易成本**：高换手率策略会被交易成本吞噬，实盘滑点可能大于预估
3. **因子衰减**：A股因子有效期通常 6-18 个月，需要持续监控
4. **黑天鹅**：极端行情下策略可能集体失效，风控止损是底线
5. **合规**：确认量化交易权限、避免违规操作（如操纵市场、内幕交易）
