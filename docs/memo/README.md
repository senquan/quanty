# Memo - 实施总结与说明文档目录

本目录存放**实施完成后的总结**、**说明文档**与**长期参考备忘**（架构、台账、政策）。
动手前的设计方案请放 `docs/plans/`。

## 📛 命名约定（2026-09-11 起）

- 一律 **`YYYY-MM-DD.<主题>.md`** —— 日期作前缀。
  - 日期取**文档自述日期**（「设计日期 / 生成时间 / 最后整理」），没有就取该文件的首次提交日；
    只知月份时用 `YYYY-MM`（如 `2026-05.tech-debt-memo.md`）。
  - 主题用英文短横线小写，与 `docs/plans/` 里的同名方案对应。
- 例：`2026-09-07.intel-module-plan.md`、`2026-09-10.intel-audit.md`、
  `2026-09-04.architecture.md`。
- **例外（不带日期，属目录基础设施）**：`README.md`（本说明）。

## 🗂 归置判定

- 是"动手前要定的**方案**"→ `docs/plans/`。
- 是"做完之后的**总结**"、或"长期要查的**说明/台账/政策**"→ 本目录。
